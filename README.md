# GitSpy 

## Description
GitSpy is an iOS application built using SwiftUI that allows you to search for GitHub users and view their profile details. With GitSpy, users can check GitHub user details such as followers, following, bio, and more. The app offers a seamless experience to interact with GitHub data using the GitHub API.


## Features
- **Search GitHub Users**: Search for any GitHub user by username.
- **View User Profile**: View detailed information about the user, including their bio, avatar, followers, and following count.
- **User Follow List**: View the list of followers and users the searched user is following.
- **Interactive UI**: A user-friendly interface built using SwiftUI.
- **Real-time Data**: Data is fetched from the GitHub API using async calls.

## Technologies Used
- Swift (for app development)
- SwiftUI (for UI development)
- Xcode (as the primary IDE)

## Devices
- iPhone
- iPad
